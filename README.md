# Story Dice 🎲

Roll picture dice (or flip cards) and invent a story using every image — a free English speaking and writing practice game.

**Play it here:** https://sundriedcorn.github.io/story-dice/

## Features

- 3D tumbling dice or deal-and-flip cards
- 700+ images in 9 categories (character, action, place, object, animal, mood & weather, plot twist, food & drink, transport)
- Category positions shuffle every roll
- 3 / 5 / 7 / 9 dice difficulty levels
- English word labels (toggleable) for language learners
- Story starters and a speaking timer
- ⛶ Present mode: fullscreen, images only — great for screen sharing in class

No build step, no dependencies — plain HTML/CSS/JS. Add your own images by appending `['🐳','whale']`-style entries in `story-dice-data.js`.
